# Feedback form (Google Forms) content

Title: The Trading Floor: tester feedback
Description: Thanks for trying The Trading Floor. This takes about 3 minutes. Please do not include passwords, brokerage details or anything private.

1. How did you use the site? (checkboxes) Browsed the feed / Posted a trade / Uploaded a replay / Built a strategy / Followed someone / Searched / Read the news
2. Which device did you use? (choice) iPhone / Android / Laptop or desktop / Tablet
3. How easy was it to sign up and set up your profile? (scale 1-5)
4. How easy was it to post a trade? (scale 1-5)
5. How useful is the site to you as a trader? (scale 1-5)
6. What did you like most? (paragraph)
7. What was confusing or frustrating? (paragraph)
8. Did anything break or look wrong? What did you do just before? (paragraph)
9. Which feature do you want next? (choice) Notifications / Direct messages / Verified results / Leaderboards / Broker import / Other
10. Would you recommend it to another trader? (scale 0-10)
11. Can we contact you for follow-up? (choice yes/no) If yes, your email (short answer, optional)
